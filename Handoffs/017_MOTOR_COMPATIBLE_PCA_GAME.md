# Motor-compatible PCA game update

The full offline IR game now uses the working motor-command program's PCA initialization and primary repeated-start register read. Initialization uses Wire.begin(SDA21,SCL22), 50 ms timeout, Adafruit driver setup, 25 MHz oscillator setting and 50 Hz frequency. Pulse conversion remains prescaler-aware with calibrated 500–2500 us endpoints. One checked STOP-separated read is retained as a fallback after an unsuccessful combined read. If neither returns an actual byte, the controller faults; no health check is bypassed and no register value is guessed.

PCA initializes before OLED and sensors. A 512-byte UART transmit buffer supports the existing bounded telemetry queue. The boot message identifies Connect Four build 017. Pi reports a six-second wait without any game snapshot and rejects incomplete snapshot-request writes. Reconnect still sends only snapshot requests and never replays moves. Missing telemetry has not been established as the same cause as the reported PCA fault.

All game behavior remains: OLED setup menus Free Play/Coach (Unavailable), Easy/Medium/Hard and Human/Robot first; button navigation; automatic staggered startup positions; persistent holding; sensor-only human input; target-only robot opening; one release per turn; qualified/atomic move commitment; correction, stop, wins, draws and physical-clear restart. No API or speech service starts.

Validation: five firmware native suites and 24 Pi tests passed, including primary combined reads, successful STOP fallback, both paths failing, missing bytes, prescaler/mode/write faults, silent serial notice, recovery and incomplete snapshot requests. Full ESP32 compilation and package verification are recorded with the rebuilt deployment artifacts. Tests cannot confirm physical operation; the reported device fault remains unconfirmed until this image is flashed and checked unloaded.

Use working code/DEPLOY.md to transfer firmware.bin, pi-update.zip and SHA256SUMS from working code/deployment. Quit the old terminal, switch external servo power off, check hashes, extract the Pi ZIP and flash the merged image at 0x0. Restart the terminal, press ESP32 EN/reset, confirm build 017 and a game snapshot. Retain any PCA detail line from diagnose if a fault remains. Clear the physical board and feed path before reset, which automatically positions motors.
